# Как дать доступ к English Up через GitHub Pages

## 1. Безопасность перед публикацией

**Никогда не добавляйте в GitHub файл `.env.local`.** В этой версии он не используется. Если раньше вы показывали OpenAI API-ключ в чате, отзовите его на https://platform.openai.com/api-keys. Нулевой баланс не делает ключ безопасным.

Не загружайте `english-up-progress.json` на GitHub — это ваш личный прогресс.

## 2. Подготовка на Windows

1. Распакуйте ZIP `english-up-v16-github-pages.zip`.
2. Откройте папку `english-up` внутри архива: непосредственно в ней должны лежать `package.json`, `app`, `components`, `lib`, `.github` и `next.config.mjs`.
3. Скопируйте эти файлы в вашу рабочую папку `C:\Users\nikit\OneDrive\Desktop\english-up` с заменой, предварительно сделав резервную копию и экспортировав прогресс.
4. Не копируйте старый `.env.local` в репозиторий; он не нужен. Не отправляйте `node_modules` или `.next`.

## 3. Самый простой способ опубликовать — GitHub Desktop

1. Установите GitHub Desktop с https://desktop.github.com/ и войдите в аккаунт GitHub.
2. Выберите `File` → `Add local repository`, укажите папку `C:\Users\nikit\OneDrive\Desktop\english-up`.
3. Если приложение предложит создать репозиторий из этой папки, согласитесь. Ветка должна называться `main`.
4. Сделайте `Commit to main` с сообщением вроде `English Up 16.0`.
5. Нажмите `Publish repository`. Для обычного публичного сайта выберите `Public`. Проект будет размещён в созданном репозитории, например `english-up`.
6. В браузере откройте репозиторий → `Settings` → `Pages` → `Source: GitHub Actions`.
7. Перейдите в `Actions`. Workflow `Deploy English Up to GitHub Pages` выполнит сборку и публикацию автоматически при отправке в `main`.
8. Если первый запуск не начался, откройте `Actions` → `Deploy English Up to GitHub Pages` → `Run workflow`.
9. Адрес готового сайта указан в GitHub Pages settings или в успешном Actions run. Для репозитория с именем `english-up` обычно это `https://ВАШ-ЛОГИН.github.io/english-up/`.

**Обратите внимание:** файлы проекта должны находиться в корне репозитория. Если в GitHub видна одна вложенная папка `english-up` вместо `package.json`, workflow не найдёт проект.

## 4. Проверьте сайт

Откройте опубликованный адрес на другом устройстве:
- Главная страница загружается, боковое меню читаемо.
- Открывается A1 и упражнение «Артикли».
- В разделе «Диалоги» появляется заказ кофе и варианты ответа.
- В Listening работает кнопка «Слушать» (если браузер имеет голос en-US).
- После ответа в грамматике прогресс сохраняется при обновлении страницы.

Если Actions показывает ошибку, откройте шаг с красным крестиком и скопируйте **только текст ошибки без токенов и персональных данных**.

## 5. Отдельный прогресс у каждого человека

Ни одна девушка или другой посетитель не увидит ваши оценки автоматически. Сайт сохраняет данные в браузере того устройства, с которого человек занимается. Перед переходом с localhost на GitHub Pages перенесите собственные данные через `Настройки` → `Экспортировать JSON` и затем `Импортировать JSON` на новом адресе.
