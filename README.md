# English Up 16.0 — бесплатная школа A1–B2 для GitHub Pages

Сайт для самостоятельного изучения американского английского на русском языке.

**Без регистрации, без OpenAI API, без секретных ключей, без сервера.** Можно открыть сайт по публичной ссылке GitHub Pages с телефона или компьютера. Сохранение прогресса — локально, в браузере каждого пользователя.

## Что работает

- Грамматика A1–B2, 71 последовательный урок и тренажёр 12 времён.
- Справочник из 49 правил с углублёнными упражнениями.
- Словарь с карточками, импортом слов, интервальными повторениями и личными коллекциями.
- Reading (48 материалов), Listening (48 материалов) с синтезом речи браузера, диктантами и проверкой понимания.
- English for America и English for Work (40 уроков) со сценариями и вопросами.
- **Диалоги** — 12 заранее подготовленных разговорных ситуаций с тремя этапами, тремя вариантами ответа на каждый этап, объяснениями, озвучкой и сохранением результата.
- Проверка уровня, план занятий, достижения, календарь, статистика, адаптивное оформление, PWA.
- Экспорт и импорт своего прогресса JSON.

**Вместо платного ИИ** используются готовые развилки диалогов и браузерная озвучка/распознавание. Это **не генеративный ИИ** и **не объективная оценка произношения**. Микрофон и некоторые системные голоса зависят от браузера, языка и сетевых возможностей.

Раздел **Writing / Письмо** полностью убран из интерфейса, ежедневного плана и статистики. Исторические записи старого профиля можно по-прежнему импортировать, чтобы не потерять другие результаты.

## Как запустить на своём компьютере

Нужен Node.js 22. В папке проекта:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:3000.

## Публикация на GitHub Pages

Детальные инструкции для Windows: [GITHUB_PAGES_GUIDE.md](GITHUB_PAGES_GUIDE.md).

1. Создайте репозиторий GitHub, например `english-up`, с веткой `main`.
2. Отправьте **содержимое этой папки** в корень репозитория (не вложенную папку `english-up`). Проще через GitHub Desktop.
3. Откройте `Settings` → `Pages` → `Build and deployment` → `Source: GitHub Actions`.
4. Дождитесь выполнения workflow `.github/workflows/pages.yml` в разделе Actions. После успешного выполнения публичный сайт доступен по `https://USERNAME.github.io/english-up/`.

Сборка настроена на `output: 'export'`; GitHub Actions устанавливает зависимости, запускает тесты, проверяет TypeScript, экспортирует сайт в `out/` и публикует его. Путь `/english-up` берётся из имени репозитория автоматически. Для репозитория `USERNAME.github.io` сайт откроется с корня.

**Никаких API-ключей в репозиторий!** `.env.local` из старой версии не нужен и исключён из Git через `.gitignore`. Если ваш старый OpenAI API-ключ когда-либо был показан кому-то, отзовите его в консоли OpenAI, даже если у аккаунта нет баланса.

## Как сохранить и перенести прогресс

В старой версии: `Настройки` → `Экспортировать JSON`. На опубликованном сайте: `Настройки` → `Импортировать JSON`.

Адрес `localhost:3000` и адрес `github.io` имеют разные хранилища браузера. Автоматического переноса нет! Каждый человек, в том числе пользователь на другом устройстве, имеет **собственный** прогресс. Чтобы синхронизировать между устройствами, нужна отдельная облачная система, которой здесь нет.

## Конфиденциальность и ограничения

- Без аккаунта. Учебная статистика, личные слова и старые сохранения остаются в localStorage данного браузера.
- При публикации исходники видны владельцам доступа к репозиторию. Не кладите в проект `.env.local`, личные данные, JSON-экспорт или токены.
- При очистке данных сайта прогресс исчезает; делайте резервные копии.
- GitHub Pages — только статический хостинг; серверного ИИ в этой версии нет.
- Большая сторонняя лексическая база зависит от стороннего источника/доступности сети. Ручной импорт TXT остаётся запасным вариантом. Условия см. в `THIRD_PARTY_VOCABULARY.md`.
- Статический сайт может работать частично офлайн после первого открытия; доступность офлайна зависит от кэша и браузера.

## Проверки

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
```

**Сборка на стороне GitHub** подтверждается только после успешного workflow; подготовка исходников и локальные тесты сами по себе не гарантируют успешную публикацию. При ошибке откройте Actions → упавший шаг и его лог.
