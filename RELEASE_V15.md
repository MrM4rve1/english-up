# English Up 15.0 — углублённая практика справочника правил

Эта версия построена поверх English Up 14.0. **Без регистрации, YouTube и принудительного подключения AI API.** Ключ локального профиля `english-up-profile-v1` и идентификаторы всех старых вопросов сохранены.

## Что нового

- **49 правил × 18 заданий = 882 задания** (было 294). Старые шесть заданий каждого правила сохранены.
- Пять ступеней: основы (6), новые ситуации (3), перевод (4), интерактивный порядок слов (3), диктант (2).
- 147 **отдельно составленных контекстных вопросов**, с индивидуальными объяснениями на русском языке.
- 196 упражнений на перевод, 147 заданий на порядок слов и 98 диктантов с озвучиванием через браузер. Эти три вида повторно используют 196 учебных предложений справочника для тренировки *разных навыков*, а не считаются независимыми новыми текстами.
- Неправильные ответы показывают правильный образец и правило. После урока можно повторить только вопросы с ошибками.
- У переводов есть **самопроверка альтернативного грамотного варианта**: это не ИИ и не автоматическая оценка смысла. При повторной тренировке результатов XP не начисляется.
- Для заданий на порядок слов сделан набор кликабельных слов с удалением и сбросом, в том числе если одно слово повторяется несколько раз.
- Для диктантов есть прослушивание и подсказка; если голос браузера не работает, его можно пропустить без добавления ложной ошибки (пропуск не засчитывается как правильный ответ).
- Улучшена автоматическая проверка регистра, пунктуации, пробелов и распространённых однозначных сокращений (например, `don't` / `do not`).

## Как обновить на Windows

1. В старой версии: **Настройки → Экспортировать прогресс**. Сохрани JSON-файл.
2. Останови терминал с запущенным сервером (Ctrl+C).
3. Распакуй архив и **скопируй содержимое папки `english-up`**, заменяя старые файлы, в:

   `C:\Users\nikit\OneDrive\Desktop\english-up`

4. Не удаляй свой `.env.local` (он не включён в архив).
5. CMD:

   ```cmd
   cd /d "C:\Users\nikit\OneDrive\Desktop\english-up"
   npm install
   npm run dev
   ```

6. Перейди по `http://localhost:3000` → **Справочник правил** → выбери тему → **Начать 18 упражнений**. При старой PWA проверь, что обновлён Service Worker, либо очисти *только кэш сайта*, не удаляя хранилище (иначе пропадёт локальный прогресс).

## Результаты проверки

- Команда `npm test` выполнена на Node 22: **133 из 133 тестов прошли**.
- `tsc` для учебного ядра (`lib/grammar-reference.ts` и `lib/rule-deep-context.ts` с зависимостями) прошёл без ошибок.
- Синтаксис TSX экрана справочника проверен TypeScript-парсером.
- **Полный `npm run build`, визуальные E2E и проверка звука на Windows не подтверждены**: необходимые внешние npm-пакеты в среде сборки не установлены. Проверь `npm run typecheck` и `npm run build` на своём компьютере после `npm install`.

## Что ещё требует внимания

- Перевод может иметь несколько равнозначных правильных формулировок. Автопроверка сравнивает их с подготовленным образцом, а не понимает смысл как преподаватель.
- Диктанты используют тот голос, который предоставляет браузер; он может звучать не как естественная речь носителя.
- В редакторской проверке каждой новой фразы в разных контекстах всё ещё возможны уточнения. Сообщай, какие задания кажутся неоднозначными: их можно обновлять, не теряя прогресс.
