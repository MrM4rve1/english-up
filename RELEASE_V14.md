# English Up 14.0 — справочник английских правил

## Содержимое

В меню добавлен пункт **«Справочник правил»**. Внутри 49 самостоятельно составленных тем A1–B2 по 10 категориям:

- артикли и существительные;
- местоимения;
- слова количества;
- основы порядка слов, вопросов и отрицаний;
- предлоги времени, места, направления, управления глаголов и прилагательных;
- похожие глаголы;
- прилагательные и наречия;
- глагольные конструкции;
- времена и планы;
- сложные предложения.

По каждой теме — русскоязычная теория, сравнение конструкций, четыре самостоятельных примера с переводом (и примеры в таблице), частая ошибка, шесть разных упражнений с проверкой и объяснениями. Итого **294 задания**.

Поиск работает по русскому и английскому, можно фильтровать A1/A2/B1/B2 и категории, сохранять избранное. Результаты отображаются в статистике, неправильные ответы поступают в «Мои ошибки»; за первое успешное прохождение темы 15 XP. Сохраняется локально без аккаунта, как и раньше.

Существующие 71 грамматическая тема, словарь, Listening/Reading/Writing, AI Teacher и другие разделы сохранены. Нет YouTube и регистрации.

## Установка

1. В старой версии зайти в «Настройки» → «Экспортировать JSON» (резервная копия прогресса).
2. Остановить сервер: Ctrl+C.
3. Распаковать архив и заменить содержимое каталога `C:\Users\nikit\OneDrive\Desktop\english-up` файлами новой версии. **Не удалять существующий `.env.local`**, если в нём настроен API-ключ.
4. Выполнить:

```cmd
cd /d "C:\Users\nikit\OneDrive\Desktop\english-up"
npm install
npm run dev
```

5. Открыть http://localhost:3000 и обновить страницу Ctrl+F5. Если сайт установлен как PWA, перезапустить приложение, чтобы обновился service worker.

## Проверка

`npm test` — 120/120. Библиотека правил и профиль проходят отдельную TypeScript-проверку; синтаксис TSX проверен. Полная production-сборка Next.js **не проверена**: npm-зависимости в среде подготовки установить не удалось.

## Ограничения

Шесть тщательно подготовленных заданий на отдельное правило, не 15–20; при этом прежние полноценные уроки A1–B2 по 20 упражнений сохранены. Система ввода сравнивает текст с эталоном и может не принять иные корректные формулировки. Озвучка зависит от браузера. Прикладная оценка уровня не заменяет официальный экзамен.
